# ComicApi – Website đọc truyện tranh tích hợp AI Chatbot

## Giới thiệu
ComicApi là dự án đồ án môn học **Lập trình Web nâng cao**, hướng đến xây dựng website đọc truyện tranh trực tuyến tích hợp chatbot AI nhằm hỗ trợ người dùng tìm kiếm, khám phá và tìm hiểu nội dung truyện.

## Công nghệ sử dụng
- **Backend:** ASP.NET Core Web API (C#)
- **Frontend:** Client Web
- **Database:** MySQL
- **ORM:** Entity Framework Core
- **Architecture:** REST API + Client, tổ chức mã nguồn theo mô hình phân lớp
- **AI:** Chatbot hỗ trợ tương tác với người dùng

## Mục tiêu
- Xây dựng hệ thống website đọc truyện tranh.
- Tách biệt backend API và frontend client.
- Quản lý dữ liệu truyện tranh bằng MySQL.
- Tích hợp chatbot AI để nâng cao trải nghiệm người dùng.

## Trạng thái dự án
Dự án đang trong quá trình phát triển.
